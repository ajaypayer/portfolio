Generative AI / Machine Learning Intern

Konect U • Machine Learning Division
📅 June 2024 – July 2024
  • Engineered and benchmarked a complete machine learning solution for Air Dust Particle Size Measurement and ambient PM2.5 concentration prediction by fusing environmental observations from precision reference monitors with distributed low-cost sensor nodes.
  • Executed rigorous exploratory data analysis (EDA), timestamp synchronization, hourly rolling averaging, multi-source dataset merging, and IQR-based outlier rejection to produce clean, high-signal training matrices using Python, Pandas, NumPy, and Matplotlib.
  • Designed and benchmarked 4 distinct regression models under identical train/validation splits: Multiple Linear Regression (MLR), Support Vector Regression (SVR), Extreme Gradient Boosting (XGBoost), and Random Forest Regressor.
  • Quantitatively evaluated performance using standard regression error indicators (MAE, RMSE, and R²). Random Forest achieved an R² of 89.2% (RMSE: 43.94, MAE: 28.86), successfully beating both linear models and gradient-boosted ensembles on sensor variance.
